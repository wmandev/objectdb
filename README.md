# ObjectDB - Releases

This repository hosts the **downloadable builds** of **ObjectDB**, a local-first knowledge and file manager for Windows.

ObjectDB keeps your notes and files on your own device - a block editor plus built-in viewers for PDFs, emails, images, Word and Excel, with OCR, full-text search, smart folders, calendar and reminders. No cloud, no account, fully private.

## Download

Grab the latest version from the **[Releases](https://github.com/wmandev/objectdb/releases)** page, or from the website:

- Website: https://objectdb.app

Two editions are provided per release:
- **Portable** - a single self-contained `.exe`, runs without installation.
- **Setup** - installer with Start Menu shortcuts (when available).

## Notes

- This repository contains **release binaries only** - not the source code.
- Windows 10 / 11 (64-bit).
- Free to use. Some Pro features are coming later.
